# فيديوهات CHAOS الإعلانية

3 فيديوهات طولية (1080×1920، 9:16) جاهزة لـ TikTok وInstagram Reels وYouTube Shorts، بالعامية المصرية،
ومعاها موسيقى متعملة من الصفر (مفيش مشاكل حقوق نشر).

| الفيديو | المدة | الفكرة |
|---|---|---|
| `out/v1-main.mp4` | 23.5 ث | الإعلان الرئيسي: "زهقت من السيرفرات الميتة؟" ← اللوجو ← الألعاب ← الـ CC ← البورصة ← اللفلات ← ادخل |
| `out/v2-bourse.mp4` | 22 ث | البورصة: "ممكن تبقى غني من ديسكورد؟" ← لوحة الأسعار ← صفقة بمكسب +267 CC ← خلي بالك ← الأوامر |
| `out/v3-invite.mp4` | 20 ث | الانفايتات: "صاحبك يساوي 1000 CC" ← الخطوات ← رتب الانفايت ← 10 صحاب = 10,000 CC |

كل فيديو طالع نسختين:

- `out/NAME.mp4`: بالموسيقى بتاعتنا (متعملة من الصفر، مفيش حقوق نشر).
- `out/NAME-nomusic.mp4`: مؤثرات بس (whoosh وضربات على القطعات) **عشان تحط أغنية ترند من جوه التطبيق**.

وجنب كل فيديو صورة غلاف (`out/*-cover.png`).

**`out/v5-trailer-vo.mp4`** (40 ث): «CHAOS: الفيلم»، تريلر سينمائي ساخر. «في عالم… السيرفرات فيه بتموت» ← شات فاضي ←
«لكن في سيرفر واحد… رفض يموت» ← BRAAAM ولوجو CHAOS ← مونتاج (ألعاب، CC، بورصة، مافيا) ← كارت تصنيف ساخر «مصنف C: فوضى
شديدة، احتمال إدمان عالي» ← «استعد» ← الفوضى بدأت. الراوي صوت *Gamal* من ElevenLabs، والـ BRAAAM والضربات والـ riser
مؤثرات ElevenLabs، والموسيقى قطعتين من ElevenLabs Music: واحدة مظلمة في الأول وواحدة ملحمية من اللوجو للآخر.
الفيديو فيه ترجمة للي بيتفرجوا من غير صوت.
فيه كمان صور حقيقية من السيرفر: فويس «among us» في أول ليلة افتتاح («سيرفر جديد… ورغم كده الفويس مليان»)، ولوحة البورصة
الحقيقية. وفيه جزء للبنات بصوت *Nadia* عن التوثيق: بتدخلي مع بنت زيك تتأكد إنك بنت فعلًا، عشان نمنع انتحال الشخصية
ولسلامتك. الصور (`vo/v5/voice.png` و`vo/v5/bourse.png`) مش في الريبو لأن فيها أسامي الأعضاء.

```bash
python3 v5_timeline.py && node render.mjs v5-trailer && python3 mixvo.py vo/v5/plan.json
```

**`out/v4-story-vo.mp4`** (43 ث): قصة شات. محادثة ديسكورد بين صاحبين: زيزو زهقان إن السيرفر بتاعهم مات، وكيمو
بيقنعه يدخل CHAOS (الألعاب، الـ CC، صفقة في البورصة بمكسب +267 CC، مكافأة الانفايت 1000 CC)، وفي الآخر بيبعتله
لينك الدعوة. كل رسالة بتتقري بصوت صاحبها من ElevenLabs: زيزو = *Ziad*، كيمو = *Karim*، والراوي في الآخر
= *Mostafa*. فيه كمان مؤثرات ElevenLabs (صوت وصول الرسالة وصوت الكاشير) وموسيقى lo-fi من ElevenLabs Music، وبعدين
drop الـ phonk مع اللوجو. الدايرة الخضرا حوالين الأفاتار بتنوّر وصاحبها بيتكلم، زي ديسكورد بالظبط.

**`out/v1-main-vo.mp4`**: الفيديو الرئيسي بتعليق صوتي مصري (ElevenLabs، صوت *Mostafa – Bold and Spirited*،
موديل `eleven_v3`) وموسيقى Phonk متعملة بـ ElevenLabs Music. ده أقوى نسخة للنشر كإعلان.

كل الأرقام من إعدادات البوت الحقيقية: 1000 CC لكل انفايت يوصل لفل 5 ويكمل 3 أيام
(`src/config/inviteRewards.js`)، `10 × اللفل` CC مع كل لفل، أصول البورصة وحد الـ 10% في الساعة وضريبة البيع 1.5%
(`src/config/store/bourse.js`).

## النشر

آخر مشهد بيقول **"اللينك في البايو 👇"**، فحط لينك السيرفر في البايو بتاعك. عايز اللينك نفسه يظهر في الفيديو؟

```bash
node render.mjs --invite discord.gg/XXXX
```

### الأغاني (مهم)

**متنزلش أغنية من تيك توك وتركّبها على الفيديو قبل الرفع**: تيك توك وإنستجرام بيكتموا الصوت أو بيشيلوا الفيديو
بسبب حقوق النشر. الصح إنك ترفع نسخة `-nomusic.mp4` وتختار الأغنية **من جوه التطبيق** (Add sound / إضافة صوت).
كده الصوت مرخص، والفيديو بيظهر في صفحة الصوت نفسه، وده بيجيب مشاهدات زيادة.

بعد ما تختار الصوت: Volume ← خلي "Original sound" حوالي 30–50% (عشان المؤثرات تبان) والأغنية 100%.

أصوات تنفع مع النوع ده (سبتمبر 2026، دور عليها في تبويب Sounds):

| الفيديو | نوع الصوت | أمثلة |
|---|---|---|
| v1 (الرئيسي) | Phonk / Brazilian funk تقيل | MONTAGEM GAME (Slowed)، Montagem Domer، ESPECTRO (Slowed)، PISADA BRUTA (Slowed) |
| v2 (البورصة) | حاجة "فلوس وثقة" | Nervy Funk، Airtel Phonk، أو أي ساوند "rich / money" ترند |
| v3 (الانفايتات) | مصري ترند (مهرجان أو بوب) | أغاني أحمد سعد الترند، "الكلام على إيه؟"، أو ابحث "ترند مصري" |

أسرع طريقة تلاقي الترند النهارده: في التطبيق ابحث `trending sounds` أو `ترند مصري` وافتح تبويب **Sounds**،
واختار صوت عليه فيديوهات كتير اتعملت **الأسبوع ده** (سهم أحمر ↗ = طالع). الترند بيتغير كل كام يوم، فغيّر الصوت مع كل نشر.

### التعليق الصوتي (ElevenLabs)

`mixvo.py` بيركّب النسخة اللي فيها تعليق صوتي: بيقص الصمت من كل جملة، يسرّعها شوية لو محتاج (`tempo`)،
يحطها في وقتها (`at`)، يوطّي الموسيقى والمؤثرات تلقائي وهو بيتكلم (sidechain)، ويظبط الصوت على -14 LUFS.

```bash
python3 mixvo.py vo/v1/plan.json    # -> out/v1-main-vo.mp4

# قصة الشات: التوقيت كله محسوب من طول الجمل الصوتية
python3 v4_timeline.py              # -> v4-story.timeline.js + vo/v4/plan.json
node render.mjs v4-story            # الصورة
python3 mixvo.py vo/v4/plan.json    # -> out/v4-story-vo.mp4
```

لو غيرت جملة في ElevenLabs: نزّلها مكان الملف القديم في `vo/v4/`، وشغّل الأوامر التلاتة من الأول، والرسايل
هتتظبط على الطول الجديد لوحدها.

ملفات الصوت (`vo/`) مش في الريبو؛ هي في الـ flow بتاع ElevenLabs "CHAOS promo — voiceover + music".

## التعديل وإعادة الرندر

كل فيديو صفحة HTML (`v1-main.html`، `v2-bourse.html`، `v3-invite.html`) تقدر تفتحها في المتصفح وتتفرج عليها
مباشرة. النصوص في الصفحة نفسها؛ كل مشهد `section.scene` ليه `data-start` و`data-end` (بالثواني)،
وكل عنصر فيه `data-at` = بعد قد إيه من بداية المشهد يظهر.

```bash
cd promo
npm install playwright            # أو اعمل link لنسخة موجودة
pip install numpy scipy imageio-ffmpeg
node render.mjs                   # كل الفيديوهات
node render.mjs v2-bourse         # فيديو واحد
node render.mjs --preview         # نسخة سريعة للمراجعة (12 فريم/ث، من غير صوت)
node render.mjs --remux           # يعيد الصوت بس (من غير ما يرندر الفريمات تاني)
```

- `shared.css` / `shared.js`: الشكل المشترك ومحرك التايم لاين (كل أنيميشن بيتوقف ويتنقل لوقت الفريم بالظبط).
- `music.py`: بيعمل الموسيقى (120 BPM) ويحط whoosh قبل كل قطع وضربة (impact) في الأوقات اللي في `body[data-hits]`.
- `render.mjs`: بيصور كل فريم بـ Playwright ويبعته لـ ffmpeg (H.264)، وبعدين يركب الصوت (AAC، -14 LUFS
  للموسيقى و-20 LUFS للمؤثرات لوحدها).
- الخطوط (Anton، Cairo، Lalezar) في `fonts/` برخصة SIL OFL.
